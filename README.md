# Dify API 测试工具

一个功能强大的 Dify API 测试工具，支持所有 Dify API 端点的测试，包括完整的知识库管理功能。

## ✨ 功能特点

- 🚀 **开箱即用** - 单文件 HTML 版本，无需安装任何依赖
- 📚 **完整的知识库 API 支持** - 创建、管理、检索知识库
- 💬 **对话与智能体 API** - 支持阻塞和流式响应
- 🔄 **工作流 API** - 执行和管理工作流
- 📝 **文本生成 API** - 测试文本补全功能
- 🎯 **智能请求构建** - 自动生成默认请求参数
- 📊 **请求历史记录** - 查看和管理历史请求
- 🎨 **美观的界面** - 基于 Ant Design 的现代化 UI

## 🚀 快速开始

### 方法一：使用单文件版本（推荐）

1. 打开 `dify-api-tester-standalone.html` 文件
2. 在浏览器中直接运行（推荐使用 Chrome、Firefox 或 Edge）
3. 输入您的 Dify API 配置：
   - **Base URL**: 默认为 `https://api.dify.ai/v1`（如果是自托管版本，请修改为您的服务器地址）
   - **API Key**: 从 Dify 应用的 API 访问页面获取

### 方法二：运行完整项目（需要 Node.js）

1. 安装 Node.js（访问 https://nodejs.org/）
2. 在项目目录下运行：
   ```bash
   npm install
   npm run dev
   ```
3. 浏览器会自动打开 http://localhost:3000

## 📖 使用指南

### 1. 配置 API 访问

在页面顶部输入：
- **Base URL**: Dify API 的基础地址
- **API Key**: 您的 API 密钥

### 2. 测试知识库 API

知识库相关的 API 包括：

#### 知识库管理
- **创建知识库** - 创建新的空知识库
- **获取知识库列表** - 查看所有知识库
- **删除知识库** - 删除指定知识库

#### 文档管理
- **通过文本创建文档** - 直接输入文本创建文档
- **通过文件创建文档** - 上传文件创建文档
- **更新文档** - 支持文本和文件两种方式
- **获取文档列表** - 查看知识库中的所有文档
- **删除文档** - 删除指定文档
- **获取文档嵌入状态** - 查看文档处理进度

#### 分段管理
- **添加文档分段** - 向文档添加新的内容块
- **获取文档分段** - 查看文档的所有分段
- **更新分段** - 修改指定分段内容
- **删除分段** - 删除指定分段

#### 知识库检索
- **检索知识库** - 根据查询词检索相关内容

### 3. 测试对话 API

- **发送对话消息** - 支持阻塞和流式两种模式
- **停止对话生成** - 中断正在生成的响应
- **获取建议问题** - 获取下一轮对话的建议
- **会话管理** - 管理对话会话
- **消息历史** - 查看历史消息
- **消息反馈** - 对消息进行评价

### 4. 路径参数处理

对于包含路径参数的 API（如 `:dataset_id`），在请求体中添加相应字段：

```json
{
  "dataset_id": "your-dataset-id",
  "document_id": "your-document-id",
  // 其他请求参数...
}
```

## 🔧 高级功能

### 流式响应

当 `response_mode` 设置为 `streaming` 时，工具会自动处理 SSE（Server-Sent Events）流式响应，实时显示接收到的数据。

### 请求历史

- 自动保存最近 20 条请求记录
- 显示请求时间、方法、URL 和状态
- 点击历史记录可以查看详细信息

## 📝 注意事项

1. **API Key 安全**：请勿在生产环境中暴露您的 API Key
2. **CORS 问题**：如果遇到跨域问题，请确保您的 Dify 服务器配置了正确的 CORS 策略
3. **文件上传**：文件上传功能需要使用完整项目版本
